# Tic-Tac-Toe

A simple console-based Tic-Tac-Toe game made using Java.

## Features

- Two-player game
- Players use X and O
- 3 × 3 game board
- Checks for winning combinations
- Detects a draw
- Prevents invalid and already occupied positions

## Concepts Used

- Java classes and methods
- Arrays
- Loops
- if-else statements
- Scanner for user input
- Basic game logic

## How to Run

Compile:

```bash
javac TicTacToe.java
```

Run:

```bash
java TicTacToe
```

## Example

```text
-------------
| 1 | 2 | 3 |
-------------
| 4 | 5 | 6 |
-------------
| 7 | 8 | 9 |
-------------

Player X, choose a position (1-9): 5
```

This project was created as a basic Java practice project while learning Java.
